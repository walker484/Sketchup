🟦 SEÇÃO 1 — DESENHO BÁSICO

Nome Ícone Para que serve Como usar Exemplo de Projeto
Lápis ✏️ Desenha linhas retas e contornos Clique no ponto inicial → mova → clique no ponto final. Digite o valor + Enter para medida exata. Desenhar as paredes de um quarto, definir limites de um terreno
Retângulo 🟦 Desenha quadrados e retângulos com cantos retos Clique em um canto → arraste → clique no canto oposto. Digite 3,50m,4,00m para tamanho exato. Fazer o piso de uma sala, base de uma casa, formato de um terreno
Retângulo Centrado 🟦+ Desenha retângulo a partir do centro Clique no centro → arraste para fora → clique para confirmar Desenhar uma mesa, piso centralizado, aberturas simétricas
Círculo ⭕ Desenha formas circulares e arredondadas Clique no centro → digite o raio → Enter. Mais lados = mais suave. Colunas, pilares, janelas redondas, formato de uma piscina
Polígono ⬡ Desenha figuras com 3 a 100 lados Clique no centro → digite o número de lados → arraste → clique Pilares sextavados, formato de uma torre, piso em formato especial
Arco ⌒ Desenha curvas e cantos arredondados Clique no ponto inicial → ponto final → arraste para definir a curvatura Cantos arredondados em uma parede, formato de um balcão, porta curva
Forma Mão Livre ✍️ Desenha linhas curvas à mão livre Clique e arraste desenhando solto → solte para finalizar Esboços rápidos, marcações, formas orgânicas

🧱 SEÇÃO 2 — VOLUME E FORMA 3D

Nome Ícone Para que serve Como usar Exemplo de Projeto
Empurrar/Puxar 🧱 Transforma superfície plana em volume 3D Clique na superfície → arraste para cima/fora → clique para parar. Digite altura exata + Enter. Paredes: desenha o chão → puxa 2,80m → parede pronta! 🧱
União 🔗 Junta dois sólidos em um só Selecione os dois objetos → clique na ferramenta → ficam um volume único Unir uma laje com uma parede, juntar dois cômodos
Subtração ➖ Remove parte de um sólido usando outro Selecione o objeto principal → clique na ferramenta → clique no objeto a remover Fazer um buraco para janela, vão de porta, canaleta em parede
Interseção ⋂ Mantém apenas onde os sólidos se sobrepõem Selecione os dois → clique na ferramenta → fica só a área comum Forma especial de encontro de vigas, corte personalizado

🔄 SEÇÃO 3 — TRANSFORMAR E MOVER

Nome Ícone Para que serve Como usar Exemplo de Projeto
Mover ↔️ Move objetos de lugar Clique no objeto → clique no ponto de referência → mova → clique no destino Colocar uma janela na posição certa, mover um cômodo inteiro
Copiar 📋 Faz cópias de objetos Segure Ctrl antes de soltar → copia. Digite o número + Enter → repete a distância Colocar 5 janelas iguais em uma parede, postes ao longo de muro
Rotacionar 🔄 Gira objetos em qualquer ângulo Defina o centro de rotação → clique em um ponto → gire → digite o ângulo + Enter Girar uma porta aberta, posicionar um telhado inclinado
Escala 📐 Aumenta ou diminui o tamanho Clique no objeto → puxe um canto → digite a proporção + Enter Redimensionar uma planta, ajustar tamanho de móvel
Espelhar 🪞 Cria imagem espelhada do objeto Selecione → ferramenta → defina o eixo de espelhamento Simetria de uma casa, lado esquerdo igual ao direito

👁️ SEÇÃO 4 — NAVEGAÇÃO E VISÃO

Nome Ícone Para que serve Como usar Exemplo de Projeto
Órbita 🔃 Gira a câmera ao redor do projeto Clique e arraste → gira livremente em 360° Ver a casa de todos os lados, conferir se paredes estão corretas
Panorâmica ➡️ Desloca a tela sem girar Clique e arraste → move a visão para qualquer direção Ver uma parte que está fora da tela sem mudar o ângulo
Zoom 🔍 Aproxima e afasta a visualização Clique e arraste para cima = aproxima; para baixo = afasta Detalhar um canto da parede, ver o projeto inteiro de longe
Vista de Cima 🔽 Olha direto de cima, perpendicular Clique → vista plana, como planta baixa Desenhar a planta no plano 2D sem distorção
Cortar Seção 🔪 Corta a casa para ver dentro Ative → aparece um plano → mova → vê o interior Ver distribuição interna sem teto/parede externa

📏 SEÇÃO 5 — MEDIR E GUIAR

Nome Ícone Para que serve Como usar Exemplo de Projeto
Fita Métrica 📏 Mede distâncias e cria linhas de guia Clique no ponto inicial → ponto final → mostra a medida. Arraste sem soltar = cria linha guia. Verificar se o quarto tem 3,50m, alinhar janelas iguais
Guia Paralela ➕ Cria linhas de referência paralelas Clique em uma aresta → arraste → digite a distância → Enter Marcar onde vai ficar a janela a 1,50m da borda
Medir Ângulo 📐 Mede graus entre duas linhas Clique no vértice → primeira linha → segunda linha → mostra o ângulo Verificar inclinação do telhado, confirmação de esquadria

🎨 SEÇÃO 6 — ESTILO E APARENCIA

Nome Ícone Para que serve Como usar Exemplo de Projeto
Pintar 🎨 Aplica cores e materiais Escolha na paleta → clique na superfície → aplica imediatamente Piso cerâmico na sala, tinta nas paredes, telha no telhado
Amostrador 🖌️ Pega cor/material de outro objeto Segure Alt e clique → pega o material → aplique em outro lugar Igualar a cor de duas paredes diferentes
Sombras 🌑 Liga e desliga sombras Clique → sombra aparece/desaparece Mostrar como o sol entra nos ambientes

📦 SEÇÃO 7 — ORGANIZAR E GERENCIAR

Nome Ícone Para que serve Como usar Exemplo de Projeto
Selecionar 🖱️ Escolhe o que você vai trabalhar Clique = 1 item; Ctrl+clique = adiciona; Ctrl+A = tudo Selecionar só as paredes para pintar de uma vez
Apagar 🗑️ Remove linhas e objetos Clique no item → apaga. Arraste por cima = apaga vários rápido Apagar linha guia que não precisa mais, corrigir erro
Grupo 📁 Junta objetos em um bloco único Selecione tudo → clique → vira um grupo com contorno azul Paredes + piso + teto = grupo "Quarto 1"
Componente 🔁 Quando muda um, muda todas as cópias Crie o componente → copie. Altere um → todos mudam! Janela: mude uma → todas 15 janelas mudam juntas! 🪟
Ocultar 🙈 Esconde objetos sem apagá-los Selecione → botão direito → Ocultar Esconde o telhado para trabalhar no interior da casa

Nome Ícone Para que serve Como usar Exemplo de Projeto

🏗️ SEÇÃO 9 — EXEMPLOS DE PROJETOS PASSO A PASSO

📌 PROJETO 1 — Um Cômodo Simples

Ferramentas usadas: Retângulo → Empurrar/Puxar → Fita Métrica → Pintar

  1. Desenhe um retângulo: digite 3,50m,4,00m + Enter
  2. Clique em Empurrar/Puxar → puxe para cima → digite 2,80m → Enter
  3. Use a Fita Métrica para conferir as medidas
  4. Pinte: piso = cerâmica; paredes = branco; teto = branco sujo

✅ Resultado: Quarto pronto em menos de 5 minutos! 🎉

📌 PROJETO 2 — Casa Completa

Ferramentas usadas: Linha → Retângulo → Empurrar/Puxar → Grupo → Componente → Cortar Seção

  1. Desenhe a planta baixa com todos os cômodos usando linhas
  2. Use retângulos para definir cada ambiente
  3. Empurre/puxe todas as paredes para 2,80m de altura
  4. Transforme cada cômodo em Grupo para não confundir
  5. Insira portas e janelas da biblioteca de Componentes
  6. Ative Cortar Seção para ver o interior

✅ Resultado: Casa completa com planta + 3D + visão interna! 🏠

📌 PROJETO 3 — Detalhe de Fachada

Ferramentas usadas: Câmera Padrão → Salvar Vista → Sombras → Pintar → Exportar Imagem

  1. Posicione a câmera de frente para a entrada
  2. Ajuste a hora do sol para ver como a sombra cai na parede
  3. Aplique os materiais: telha, tinta, porta, janelas
  4. Salve a vista como "Fachada Principal"
  5. Exporte em alta resolução para enviar ao cliente

✅ Resultado: Imagem profissional pronta para apresentação! 📷

💡 DICAS EXTRAS IMPORTANTES

Guia de Sobrevivência no SketchUp

  • 💾 Salve sempre em .skp — É o formato nativo, nunca perde qualidade
  • 📦 Use grupos e componentes — Seu projeto não vira uma bagunça impossível de editar depois
  • 🌱 Comece simples — Não tente fazer uma mansão no dia 1. Comece por um quarto, depois cresça
  • 🖱️ Aprenda o mouse primeiro — Roda = girar/zoom; Shift+roda = deslocar — isso é 50% do que você faz!
  • 📏 Digite direto no teclado — Não confie no olho! Sempre digite o número + Enter — medida exata é tudo!
  • ↩️ Ctrl+Z = Desfazer — Errou? Aperta isso que volta! Não tem problema errar!
  • 🖱️ Botão direito do mouse — Sempre clique nele — é onde ficam 80% das opções que você precisa
  • 🏬 Use o 3D Warehouse — Por que desenhar uma cadeira se alguém já fez? Baixe e use! Economiza horas!
  • 🌑 Sombras só no final — Trabalha mais rápido sem sombra. Liga só quando for apresentar
  • 📝 Um passo de cada vez — Planta primeiro → depois paredes → depois detalhes → depois telhado
